# 夜幕之下 · AI 狼人杀

一个无需安装依赖的浏览器游戏。支持 6 人、12 人全 AI 自动对局。

## 运行

```sh
npm start
```

打开 http://127.0.0.1:4173 。使用 API Agent 必须从这个启动地址访问，并保持启动窗口运行；直接打开 `index.html` 仅支持本地模拟。

Windows 可以双击 `start-game.cmd` 启动（需要已安装 Node.js）。游戏服务会在后台运行，关闭启动窗口不会停止服务；需要停止时双击 `stop-game.cmd`。服务异常退出后会自动重启，启动、退出和错误信息保存在 `logs/game-lifecycle.log`、`logs/game.stdout.log` 和 `logs/game.stderr.log`。

## 一键自动对局

先在 Agent 配置页为席位填写模型、接口与密钥，再回到游戏桌点击“开始游戏”。系统随机分配角色，所有席位（包括 1 号位）按规则自动执行夜间技能、白天依次发言、投票、平票 PK 与猎人技能，直至结算胜负，不需要手动推进阶段。未配置 API 的席位及 API 失败的当次行动使用本地模拟。

默认使用上帝视角，显示真实身份及已结算的夜间行动；可切换普通观战，隐藏夜间身份、行动席位、目标及私有查验，终局后揭晓身份。字幕、旁白历史、动态和导出遵守所选视角。可选择快速、标准、慢速观战节奏（仅调整行动间隔，不改变模型响应速度），随时暂停 / 继续；暂停时当前已发出的请求会完成，声音和后续行动等待继续。重置或切换房间会取消旧对局。结束后点击“再来一局”重新洗牌；暂停时可以调整席位配置，连接测试请在开局前进行。收起记录同时隐藏左侧动态、旁白和右侧发言记录，不停止语音；点击人物重新展开并筛选该席位记录。

## 已有功能

点击开始后先逐席播放匿名卡背飞行动画（6 人约 1.6 秒、12 人约 2.2 秒），然后只随机分配一次身份，再依次翻牌，翻牌完成前不执行 Agent 行动。上帝视角展示真实身份，普通观战仅显示“身份已分配”，不会朗读隐藏身份。开局、夜晚、天亮、讨论、投票、PK、放逐和猎人使用约 1.8 秒的光色、暗化、图案及标题转场，与旁白同时进行。胜利后播放约 5 秒阵营庆祝，好人使用暖金光和彩屑，狼人使用暗红月光及金红粒子；所有获胜成员（含已出局成员）保持高亮，结果持续保留，可点击“再来一局”。暂停冻结音画，重置和换房清理旧效果；减少动态效果时使用静态高亮。

6 人间采用暗色庄园场景：烛光背景、雕花木桌、红棕皮椅和六位成年动漫人物，按顺时针分为前后两排。羊皮纸名牌实时显示座位号、昵称、身份（按视角）、存活状态、连接状态和简短提示，文字可选中；人物外貌固定跟随席位，不随随机身份改变，也不以服装或道具暗示身份。12 人间采用独立的宽幅双弧庄园圆桌，保留原六位立绘，新增六位正式人物与原六位一起围桌而坐；游戏桌、导航、Agent 配置、规则手册及交互控件统一采用棕黑、古金与羊皮纸配色，身份以高对比色块、图标和文字显示。

在“Agent 配置 → 对应玩家卡片 → 配置 Agent / 声音 → 席位立绘”中，可选择已制作人物或“使用当前头像”，十二张正式立绘均配有闭眼版本和记录缩略图。立绘选择随席位保存在浏览器，原头像、声音、模型及密钥配置保持兼容；发言记录中的缩略图与当前席位形象一致。出局人物灰化并标注“已出局”，仍可点击筛选记录；立绘加载失败会使用原头像并保留完整名牌，场景素材失败时提供基础背景及桌面。

发言气泡使用深棕半透明底、细金边、暖色文字及小尾尖，不重复显示姓名和播放状态（这些信息保留在名牌）。六张立绘分别记录嘴部锚点，随形象与缩放定位；12 人及头像回退使用头像下半部。气泡按标点和最多 16 个字符分句，每次最多两行，随播放进度逐字展示当前一句；全文保留在发言记录。自然音频使用播放进度估算分句节奏，系统朗读优先使用字符边界事件，尚非逐字音频强制对齐。定位优先靠近嘴部，再避开面部、名牌和边缘。准备声音、播放、暂停及结束均有对应状态，播放时人物轮廓呈金色脉动光晕，暂停时停止，减少动态效果时使用静态高亮。成功播放后停留 250 毫秒，发言前不额外等待标准的 1.2 秒；模型请求与语音生成仍需等待。关闭声音或播放失败时，按每秒约 5 字提供 4–20 秒逐句阅读时间。小屏幕可左右滑动场景，当前发言者会进入可见范围。

桌面左侧上下两个面板分别显示“对局动态”和“旁白”，右侧独立显示完整“发言记录”；三处各自滚动并保留位置。平板及更窄屏幕将左侧面板移到桌面下方。点击席位或选择玩家可筛选发言，记录显示轮次、普通或 PK 发言、时间，并支持重播。查看旧记录时不会被新消息拉回底部，可点击新记录提示回到最新。手机使用可展开的底部记录栏。点击“全屏观战”隐藏页面导航，保留圆桌、可收起的记录栏、暂停、语音和节奏控制；点击“退出全屏”或按 Esc 返回。浏览器未开放全屏时会使用页面内沉浸布局。

左侧旁白面板解释开局、夜晚、天亮、讨论、投票、PK、放逐、猎人和胜负。上帝视角按守卫、狼人、预言家、女巫分步展示已确认且通过规则校验的行动，配合行动者、目标、药瓶和保护光／紫色扩散效果。狼人仅播报最终袭击目标，死亡仍在天亮统一结算；天亮不重复逐条复述。普通观战仅显示通用夜间流程及公开结果，隐藏行动者、目标、查验、用药和专属音效。旁白使用固定文案和自然中文云扬音色，冷静语气、正常语速，不调用聊天模型；与玩家对白串行播放，失败或关闭时保留字幕并继续。旁白开关与玩家对白开关独立。切换视角立即停止旁白和音效，清除目标高亮，刷新对应记录，不重播历史。视角、记录栏展开状态和旁白开关保存在浏览器，本局记录重置后清空。观众事件与上帝视角信息不会传入 Agent 上下文。

上帝视角每夜会播放“天黑请闭眼”，并在存活的守卫、狼人、预言家、女巫行动前播放对应的睁眼与行动口令，例如“狼人请睁眼，狼人请杀人”；行动结果后提醒该角色闭眼，天亮播放“天亮了，请睁眼”。口令与行动解说使用同一旁白开关和串行语音流程，暂停、重置及视角切换会一并处理；普通观战隐藏角色专属口令。

投票时席位依次显示“待投票／正在投票／已投票”，全部提交后按座位逐一揭示“投给 X 号／弃票”，旁白明确播报“X 号玩家投给 Y 号”或弃票，并累计票数，然后进行放逐或 PK。投票及得票提示位于头像右上方，按实际头像和场景边界避让，不再放在名牌底部，避免 5 号席位超出画面。PK 候选人标记为本轮不投票，第二轮清空上一轮提示；无效票、弃票和平票继续由规则引擎结算。

已出局玩家按规则结算原因显示不同的图标、颜色和文字：红色“遭狼袭”、紫色“中毒出局”、金色“投票放逐”、蓝色“猎人击中”。人物适度灰化，原因标签和名牌仍清晰可见。普通观战在终局前将狼袭与中毒统一显示为“夜间出局”，不通过文字、颜色或样式泄露死因，终局后揭晓。

“音乐”提供独立开关和音量，默认开启、15%，设置保存在本浏览器。点击开始后播放本地原创的 64 秒悬疑氛围循环，人声播放时平滑压低至设定音量的 22%，结束后恢复。暂停和继续会保留音乐进度，重置、换房及对局结束停止，不会叠加多个播放实例；加载失败不阻塞游戏。素材与复现说明见 `assets/music/README.md`。

人物随主持口令睁眼／闭眼：入夜全员闭眼，上帝视角中轮到行动的角色睁眼，行动讲解结束后闭眼，天亮存活玩家睁眼。普通观战整夜统一闭眼，不通过动画泄露身份；出局玩家保持闭眼。6 人间六位默认立绘使用从原图派生的闭眼图层，平时有错开的轻微眨眼；12 人及自定义头像采用带闭眼符号的遮罩提示，不猜测上传头像的五官位置。暂停冻结动画，重置清除旧状态，系统减少动态效果时取消眨眼。素材派生脚本为 `scripts/generate-eyelids.py`，不调用图片接口、不读取密钥。

“音效”开关和音量独立于对白及旁白，默认开启、音量 30%，保存在浏览器。14 段本地短音效随项目保存，覆盖洗牌、飞牌、翻牌、夜间低鸣、独狼长嚎、守护、查验、解药、毒药、投票、放逐、猎人枪声及两种胜利；无需外部音效服务或密钥，另有可独立关闭的背景音乐。点击开始或继续后启用，播放被限制或素材失败时静默跳过；人声播放时自动降低音效音量。素材与复现说明见 `assets/sfx/README.md`。

点击“规则介绍”会打开当前 6 人或 12 人房间的规则，并播放内置的自然中文女声讲解，规则手册中也有“语音介绍规则”按钮。讲解词采用主持人口吻，分别对应两种房间，支持停止和重新播放。对局中讲解规则或重播对白会暂停游戏，结束后点击“继续对局”。暂停会暂停正在播放的声音，重置或更换房间会停止旧语音并清除气泡。

规则讲解使用已生成的 MP3（微软晓晓神经网络女声，语速降低 5%，保持原音高），属于合成语音，并非真人录音。播放无需联网、额外语音 API、密钥或 Python，也不依赖本机安装的朗读音色。音频失败时显示重试提示并保留文字，不自动切回系统朗读。新增音频文件需重启旧游戏服务后刷新页面。

玩家对白默认使用联网生成的自然中文合成音色，不再依赖浏览器基础朗读。当前电脑已安装生成依赖；更换电脑可先双击 `setup-voice.cmd`（需要 Python 3.10 或更新版本）。生成时仅发送公开发言、音色和语速，不发送聊天密钥、隐藏角色或夜间信息。音频只在内存中传输与播放，不写入文件。生成或播放失败会提示原因，保留文字并继续对局，不自动换成系统朗读。关闭对白语音不会关闭规则讲解。

在“Agent 配置 → 对应玩家卡片 → 配置 Agent / 声音 → 这位玩家的声音”中，可独立选择语音方式、音色、语速和情绪风格，并用“试听当前声音”预览未保存的设置。新增“跟随庄园人物 / 自定义声音”：6 人间默认按立绘匹配音色，绯发来客用晓晓、沉静绅士用云扬、夜色旅人用云希、晚宴宾客用晓伊、银发访客用云健、月光来客用晓臻（台湾口音），男女各三位，语气随台词变化。切换立绘会切换推荐，使用原头像时沿用席位声音。检测到旧版自定义声音的配置继续使用自定义；也可主动切换模式。12 人间提供按人物匹配的推荐音色，原有自定义声音继续保留。声音跟随外观或席位，不随随机身份改变。情绪可随公开台词变化，或固定为冷静分析、轻松活泼、怀疑追问、坚定反驳、紧张辩解、低落遗憾。自然中文音色通过语速及音高变化表现语气，仍属于合成语音，并非真人录音。

需要更丰富的情绪演绎时，选择“情感语音接口”，单独填写语音接口地址、语音模型、音色 ID 和语音密钥。服务需兼容 `POST /v1/audio/speech`，返回 MP3 并支持 `instructions` 语气指令；根地址和 `/v1` 自动补全为 `/v1/audio/speech`。聊天模型（例如 `gpt-6-astra`）并不等于语音模型，需使用供应商明确支持的语音模型。语音接口不会自动使用聊天密钥。支持勾选在本浏览器记住语音密钥（明文本地保存），取消勾选并保存可删除；服务器和对局导出均不保存语音密钥。实际情绪效果由所用语音模型决定。也保留“系统基础朗读”供手动选择，但它不支持情绪演绎。

本次继续默认使用免费音色，不要求新增语音服务。根据原文识别怀疑、坚定、紧张、轻松及遗憾，以有限范围的语速、音高和标点停顿改善语气，保留人物音色与用户自定义配置，不增加台词、口头禅或呼吸文字。完整发言仍一次生成，不逐短句请求。声音设置提供“分析／追问／辩解”三种试听文本。免费服务不支持完整的情绪表演，不能等同于真人录音。

讲解词位于 `assets/rules-narration.json`。修改规则后，可用 `python -m pip install -r scripts/requirements-voice.txt` 和 `python scripts/generate-rule-audio.py` 重新生成两份音频；仅制作过程需要联网，发送内容只有公开规则文本。脚本使用现有代理环境设置，生成文件及文本校验值记录在 `assets/rules-audio-metadata.json`。这两个 JSON 和制作脚本不对网页开放。也可将相应 MP3 替换为自行录制且有使用权的真人讲解，并同步校验元数据。

- 6 人：2 狼人、1 预言家、1 女巫、2 平民。
- 12 人：4 狼人、预言家、女巫、猎人、守卫各 1，4 平民。
- 随机发牌、夜间技能、白天发言、公开投票、平票 PK、猎人开枪及胜负结算。
- 每个席位单独设置名字、卡通头像、性格、模型、接口和 API Key。
- 内置 16 个动物形象，也可上传 PNG、JPG、WebP 头像。
- 对局记录导出，桌面与手机布局。

## 独立 AI 接口

### 图片制作密钥（独立于玩家）

通过游戏导航“图片素材设置”或 http://127.0.0.1:4173/image-settings.html 打开本机设置页面。填写华龙图片接口密钥并点击“加密保存到本机”；当前使用 `https://api-fast.hualong-ai.com` 和 `gpt-image-2.5-sunburst`，沿用原来加密保存的图片密钥。保存本身不请求供应商、不产生出图费用，也不代表图片模型权限已经验证。首次使用新页面时需要重启旧游戏服务。

此专用密钥由 Windows 当前用户的 DPAPI 加密，存于 `%LOCALAPPDATA%\NightfallWerewolf\image-provider.json`，刷新和重启服务后仍可使用。网页接口只返回“是否已保存”和保存时间，不返回明文或加密后的密钥；输入框保存成功后清空，不把密钥写入浏览器存储、玩家配置或项目素材。后续制作工具可通过本机 `image-config.cjs` 的 `createImageConfigStore().loadCredential()` 读取，直接用于制作进程，不打印密钥。此文件仅能由原 Windows 账户在原电脑解密，复制项目不会复制该密钥。

设置页只保存制作凭据，不提供游戏运行时的图片生成接口。本次已通过华龙图片接口及 `gpt-image-2` 权限验证，并生成正式庄园背景、木桌及六位人物素材。游戏启动、发牌、发言和换房均使用本地图片，不再调用图片模型。

生产素材位于 `assets/manor/`，共 38 份 WebP（背景、透明桌面、十二位透明人物、十二份缩略图及十二份闭眼版本），通过静态资源白名单提供。原始生成图和提示词分别位于 `output/imagegen/` 与 `output/imagegen/prompts/`，人物总览为 `output/imagegen/portrait-contact-sheet.jpg`，尺寸及压缩信息见 `output/imagegen/asset-metadata.json`。制作脚本 `scripts/prepare-manor-assets.py` 完成纯色背景提取与 WebP 压缩；这些制作文件不会由游戏静态服务公开。

Agent 配置中选择“独立 API Agent”，填写 OpenAI 兼容的接口地址、模型 ID 和自己的 API Key。支持填写网站根地址、`/v1` 地址或完整的 Chat Completions 地址。根地址和 `/v1` 会自动补全为 `/v1/chat/completions`，自定义完整路径保持不变。

例如接口地址填 `https://api.hualong-ai.com`，模型填 `gpt-6-astra`，会请求 `https://api.hualong-ai.com/v1/chat/completions`；模型是否可用取决于供应商和你的账户权限。

测试连接与对局请求都经由游戏本地服务的 `POST /api/chat` 转发，不要求供应商允许浏览器跨域。点击测试会真实请求接口。运行中会分别请求技能、发言和投票；失败时明确提示并回退本地模拟，不伪造连接成功。上游最多等待 60 秒，网页最多等待 65 秒；重置对局会取消进行中的请求。

请求格式为 `POST`、`Authorization: Bearer …`、`{model,messages,temperature,max_tokens}`。响应读取 `choices[0].message.content`。发言返回 `{"speech":"…"}`；选择返回 `{"target":1}` 或 `null`；女巫返回 `{"save":true,"poison":null}`。API 使用从 1 开始的席位编号。游戏会校验并结算行动。

每个 Agent 仅获得自己的身份、阵营可知信息、技能结果、存活状态、跨轮公开发言与票型。完整规则、合法目标和人格会进入它的独立提示词。目标统一使用从 1 开始的座位编号，非法目标会明确提示并回退。本地模拟使用规则与发言模板，不等同于大语言模型。

名字、头像、性格和接口配置保存在浏览器。每个席位默认勾选“在此浏览器记住 API Key”，点击保存后密钥以明文保存在该浏览器的本地存储中；刷新页面或重启游戏服务后自动恢复。请固定使用同一浏览器及 `http://127.0.0.1:4173`，更换浏览器、使用无痕模式、切换 localhost/端口或清理网站数据都不会共享原配置。取消勾选并保存会删除该席位已存密钥，仅在当前页面内存中使用；清空密钥后保存也可删除它。旧版本未保存的密钥无法恢复，需要重新填写并保存一次。

点击“批量测试连接”后，所有 API 卡片立即进入等待状态，随测试进展显示“连接中”，完成后分别显示成功或失败；按钮显示当前进度与正在测试的席位。测试期间不能重复测试、修改配置或开始游戏。游戏桌同步显示“API 在线 / 离线 / 响应慢 / 未测试 / 连接中”，本地模拟有独立标识。状态以最近一次测试或游戏请求为准，并非持续在线监测；请求失败显示离线并回退本地模拟，下次请求成功自动恢复在线。刷新页面后状态回到未测试，修改接口、模型或密钥后需重新测试。

连接测试使用 Responses 流式请求（`stream:true`），携带席位实际的 `high` 或 `xhigh` 推理强度，收到首个有效 Responses 事件即结束探测并显示成功。该结果表示接口已接受测试请求，完整生成结果由实际对局请求继续验证。接口明确拒绝流式参数时，自动回退一次非流式请求。接口直接返回普通 JSON 时按 Responses 结果解析，350 token 测试预算耗尽时仍可确认接口已接受请求。

每次连接尝试收到响应头前的等待上限为 10 秒，可恢复网络错误最多重试一次，整个测试最长 60 秒。收到响应头后等待结果超时，会显示黄色的“已连通 · 响应较慢”。批量测试中，接口、模型、密钥与推理强度都相同的席位共享一次请求结果。同一主机依次测试，不同主机最多 3 个并发，按钮显示进度与正在测试的席位。连接测试使用共享 HTTP/HTTPS keep-alive 连接池和 TLS 会话缓存。

每次测试在 `logs/agent-requests.jsonl` 写入一条 `task` 为 `connection-test` 的记录，包含席位、接口主机、模型、推理强度、请求方式（stream / json / fallback）、响应头与首个事件耗时，以及失败阶段与尝试次数。

转发服务仅在请求期间使用密钥，不写入服务器文件或日志；导出的对局记录不包含密钥，错误提示不会回显供应商可能包含密钥的原始报错。批量测试失败时，每个席位会显示具体原因；缺少密钥的席位也会提示补填。

本地服务只监听 `127.0.0.1`，转发接口校验同源访问、请求格式和大小（最大 1MB），仅允许 HTTPS 或本机 HTTP 目标地址，不跟随接口重定向。正式部署仍需增加用户鉴权和部署环境适用的访问控制。

连接失败时会分别提示密钥无效、模型不可用、接口路径错误、供应商拒绝访问、余额/频率限制、网络或证书异常、超时和响应格式错误。如果提示游戏服务需要重启，重新双击 `start-game.cmd` 后刷新页面；查看后台运行状态和停止原因可检查 `logs` 文件夹。

2. 保存并确认六镜头剧本，在“管理独立图片密钥”中检查当前图片模型配置。点击制作六位定妆照并确认费用后，程序以六张本地立绘为参考，逐张请求华龙 `/v1/images/edits`。人物以中性背景展示脸型、头发和服装，不包含秘密或随机阵营。
3. 图片可放大、查看实际提示词、修改公开描述并单张重做。检查全部人物并整组确认后，明确点击制作分镜；分镜使用本镜出场人物的已确认定妆照、统一空间设定与前镜结尾，无人物镜头只引用本地庄园图作为风格参考。检查六张 16:9 起始图并整组确认后，才可制作视频。
4. `story60-refs-v1` 请求 `image: {url: data URI}` 指定起始图，`reference_images: [{url: data URI}]` 按座位排序传入出场人物。提示词中起始图为 `<IMAGE_0>`，人物从 `<IMAGE_1>` 开始；环境镜头不附人物参考。图片内容在提交时从本地读取转为 Base64，不要求华龙访问 localhost，不支持时明确报错，不降级为纯文字生成。画面仍逐镜生成，复用现有统一旁白与 60 秒合成流程。
5. 完整预览并明确采用后才绑定开场。旧任务与已确认图片快照保持独立，修改席位不会改变正在制作的视频参考素材。

每个剧本版本只有一个图片任务，重复点击复用任务；图片重做递增修订号，已完成文件与提示词留在历史中。重做人像仅让实际包含该人物的分镜需要重新制作，全部分镜确认状态失效；视频任务按剧本版本、制作方案和图片修订去重。视频保存自己的一组图片副本，因此原图片任务继续编辑也不会污染已提交的视频。旧修订视频仍可预览，但要采用新修订需重新制作并确认。

图片任务及不可变媒体位于 `%LOCALAPPDATA%\NightfallWerewolf\stories\art`，通过受控 `/api/story-art-media` 提供 PNG 预览，原始立绘副本和任务文件不直接公开。图片与视频密钥继续分别使用 Windows 当前用户加密；玩家聊天密钥不会用于图片制作。收到图片立即保存原始字节，再本地解码为 PNG；转换失败可点击“继续处理原图（不计费）”。提交结果不明、成功响应没有可保存图片或服务在提交时中断，均停止自动重发，先核对供应商后台；明确点击重做才再次生成。重启后未提交部分可继续，已完成部分保留。

自动测试增加图片保存与恢复、确认门槛、修改失效范围、真实 multipart 参考字节、Base64 视频内容与编号、去重、未知响应不重发、媒体白名单及秘密隔离。测试使用模拟供应商，不产生图片或视频费用；正式人物一致性仍需按工坊步骤生成并检查。

## API 离线等待、全屏与人物登场介绍

六／十二人全屏与沉浸观战默认收起记录，记录以浮层展开，退出后恢复普通页面偏好。剧情工坊新增独立公开剧情身份和首次登场姓名条，支持逐镜时间、左右位置、画面预览和确认；新成片、预演与既有视频独立副本使用同一合成样式。建议登场位置仍需人工核对画面，旧视频播放与恢复不受影响。

本轮 249 项功能测试、3 项真实媒体合成测试通过。现有采用版已制作 90 秒带人物介绍的预览副本，原视频尚未替换；未调用收费生成接口。使用方法、预览地址和完整验收记录见 `output/upgrade-20261116-delivery.md`。
